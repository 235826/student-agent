# Student Agent 产品主线

## 一句话

一个以任务为中心的 todo app：课程和日历提供时间背景，Agent 在需要时帮助解析、安排和重排。

## 核心闭环

```text
记任务 → 今天做什么 → 完成/延期 → 需要时让 Agent 安排
```

没有估时、可用时间或计划，也必须能正常使用。

## 主导航

- 今日
- 任务
- 日历
- 收件箱
- 设置（侧栏底部）

学习计划不再是一级导航。安排是从今日或任务触发的动作。

## 页面职责

### 今日

- 快速添加任务；支持自然语言识别日期、时间、优先级、标签、预计用时和清单。
- 输入时展示解析预览，保存前可继续修改原文。
- 逾期与今天要做的任务分开显示；勾选即完成，可撤销。
- 任务可就地改期到今天、明天、本周末、下周一或清除截止。
- 接下来：近期任务。
- 今天的固定安排：课程、会议、考试。
- Agent 建议：只在有值得提示的事情时出现。
- 按需打开安排面板。

### 任务

- 普通任务列表：标题、截止时间、优先级、状态、所属清单。
- 智能视图：全部、今天、已计划、无日期、已标记、已完成、垃圾箱；可按清单、标签和状态筛选。
- 搜索由服务端执行，覆盖标题和描述；输入有短暂防抖。侧栏今日/逾期角标使用汇总接口，不加载全量任务。
- 任务列表每次加载 50 条，可继续“加载更多”；手动排序需先加载完当前列表。
- 任务可设置每天、每周或每月重复；完成后自动生成下一次并保留标签、清单和估时。撤销完成时，若下一次任务未被修改则自动移除。
- 重复任务需要截止时间；不复制子任务和前置依赖，但会保留相关链接。
- 任务可保存最多 20 个 http/https 相关链接，编辑时每行一个，任务卡上可直接打开。
- 任务可一键标记为重点，星标状态在任务卡和今日页同步显示。
- 清单支持新建、改名、改色、排序和删除；删除清单时任务回到收件箱。
- 任务可添加多个标签；输入新标签时自动创建，点击标签可快速筛选；标签管理支持改名、删除和查看使用次数。
- 勾选完成或恢复为待办；移入垃圾箱后可从提示撤销。
- 完成、延期、编辑、垃圾箱；完成时间会记录并按日期展示。
- 截止时间支持仅日期（全天）和快速改期。
- 任务详情支持内联子任务 checklist：直接添加、勾选完成、恢复和查看进度。
- 任务可按“手动排序”排列：桌面拖动卡片，移动端使用上移/下移按钮；排序结果持久化。
- 完成任务时可记录实际耗时、原因和感受；计划按剩余工时安排。
- 依赖、估时、来源和计划块默认折叠。

### 日历

- 课程和事件周视图。
- 计划块作为可选浅色背景。
- 事件类型只作为小标签。

### 收件箱

- 文本、图片、自然语言输入。
- 草稿校对。
- 确认后创建任务或事件。

### 设置

基础：

- 时区
- 每周可用时间
- 休息时间

高级：

- 并行规则
- 事件类型
- 计划版本
- 课程默认设置

账号：

- 当前账号
- 创建新账号
- 退出

## 业务原则

- 任务优先，计划是可选增强。
- Agent 只建议，不自动修改任务或计划。
- 高级规则只放在设置里。
- 主界面不展示计划版本、审计、来源和内部状态。
- 课表、事件、计划能力保留，但不抢占任务主路径。

## 验收

1. 打开首页可以一次输入创建任务。
2. 没有估时和计划也能完成任务。
3. 今天页清楚区分任务和固定安排。
4. 收件箱只负责导入和草稿。
5. 安排必须按需打开，预览后才能采用。
6. 手机上四个主导航项可用。
