# Student Agent 产品主线

## 一句话

一个以任务为中心的 todo app：课程和日历提供时间背景，Agent 在需要时帮助解析、安排和重排。

## 核心闭环

```text
记任务 → 今天做什么 → 完成/延期 → 需要时让 Agent 安排
```

没有估时、可用时间或计划，也必须能正常使用。

## 主导航

- 今日
- 任务
- 日历
- 收件箱
- 设置（侧栏底部）

学习计划不再是一级导航。安排是从今日或任务触发的动作。

## 页面职责

### 今日

- 快速添加任务。
- 今天要做：逾期、今天到期、进行中。
- 接下来：近期任务。
- 今天的固定安排：课程、会议、考试。
- Agent 建议：只在有值得提示的事情时出现。
- 按需打开安排面板。

### 任务

- 普通任务列表：标题、截止时间、优先级、状态。
- 完成、延期、编辑、垃圾箱。
- 完成任务时可记录实际耗时、原因和感受；计划按剩余工时安排。
- 父子任务、依赖、估时、来源和计划块默认折叠。

### 日历

- 课程和事件周视图。
- 计划块作为可选浅色背景。
- 事件类型只作为小标签。

### 收件箱

- 文本、图片、自然语言输入。
- 草稿校对。
- 确认后创建任务或事件。

### 设置

基础：

- 时区
- 每周可用时间
- 休息时间

高级：

- 并行规则
- 事件类型
- 计划版本
- 课程默认设置

账号：

- 当前账号
- 创建新账号
- 退出

## 业务原则

- 任务优先，计划是可选增强。
- Agent 只建议，不自动修改任务或计划。
- 高级规则只放在设置里。
- 主界面不展示计划版本、审计、来源和内部状态。
- 课表、事件、计划能力保留，但不抢占任务主路径。

## 验收

1. 打开首页可以一次输入创建任务。
2. 没有估时和计划也能完成任务。
3. 今天页清楚区分任务和固定安排。
4. 收件箱只负责导入和草稿。
5. 安排必须按需打开，预览后才能采用。
6. 手机上四个主导航项可用。
